# AetherTwin replay data

Static replay data for the AetherTwin showcase (https://aethertwin-showcase.vercel.app/replay): a 30-second recording
from the KIIT IoT lab on 5 Nov 2026 (Unitree L2 LiDAR, hand-pushed cart), processed offline by the AetherTwin pipeline
and written in SHOWCASE FORMAT v1 (`index.json`, `bootstrap.json`, `chunks/*.bin.gz`, `assets/`). It is a recorded
replay, not live, and the hardware is not verified. Served by GitHub Pages so the replay's bytes do not count against
the website host. Source code: https://github.com/NamanSingh69/aethertwin-lab
